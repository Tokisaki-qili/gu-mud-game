# 🕷️ 蛊真人 - MUD 文字冒险

基于小说《蛊真人》世界观的多分支文字冒险游戏，纯前端实现，浏览器打开即玩。

## 🎮 在线游玩

**GitHub Pages（永久链接）：**
👉 [https://tokisaki-qili.github.io/gu-mud-game/](https://tokisaki-qili.github.io/gu-mud-game/)

> 也支持下载 `index.html` 到本地用浏览器打开（离线也能玩）。

## 🧭 故事背景

你——古月方源，古月山寨的一名普通少年。在一年一度的「开窍大典」上，你成功开辟空窍，踏上了蛊师之路。从山寨出发，探索翠微山、挑战妖兽、深入迷雾福地、收集稀有蛊虫——你的选择将决定命运走向。

## ⚙️ 游戏系统

| 系统 | 说明 |
|------|------|
| **空窍系统** | 可升级容量（5-7+），可视化装备位，自由管理蛊虫 |
| **修为系统** | 一转至九转，每转分初阶/中阶/高阶/巅峰 |
| **蛊虫系统** | 12种蛊虫，分攻击/防御/治疗/特殊四种类型 |
| **装备系统** | 武器/防具/饰品三栏，可购买或打怪掉落 |
| **蛊虫融合** | 8条配方，低阶蛊虫合成高阶，最高可达五转灭世蛊 |
| **仙道杀招** | 月光斩/雷火天降/天威浩荡/不灭金身，需对应蛊虫发动 |
| **福地副本** | 迷雾福地三层（外围雾狼→内围雾蛟→核心雾龙+涅槃蛊） |
| **成就系统** | 石魔杀手/福地之主/为民除害/蛊虫炼师/福地征服者 |
| **存档系统** | localStorage 本地存储，自动存档+5个手动档位 |

## 🗺️ 地图

```
古月山寨（起点）
  ├── 藏经阁（学知识）
  ├── 商铺（买装备/蛊虫）
  ├── 融合室（蛊虫融合）
  ├── 任务堂（接委托）
  └── 翠微山
       ├── 密林（火球蛊·冰晶蛊·灵泉）
       ├── 矿场（石魔·石皮蛊·杀招残卷）
       └── 山顶（修炼突破·古文字·迷雾福地入口）

迷雾福地
  ├── 外围（雾狼·金刚蛊）
  ├── 内围（雾蛟·蛟龙鳞甲）
  └── 核心（雾龙·涅槃蛊·结局）
```
