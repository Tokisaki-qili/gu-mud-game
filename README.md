## 🧭 故事

你——**古月方源**，古月山寨的普通少年。开窍大典上，你成功开辟空窍，踏上蛊师之路。

从山寨出发，探索翠微山、击败妖兽石魔、闯入迷雾福地、收集稀有蛊虫、融合灭世神蛊——**你的每个选择都在书写传奇**。

---

## ⚙️ 游戏系统

| 系统 | 说明 |
|------|------|
| 🔮 **空窍** | 装备蛊虫的空间，容量可升级（5 → 7+），可视化管理 |
| 📈 **修为** | 一转至九转，每转初/中/高/巅峰四阶，山顶修炼可突破 |
| 🐛 **蛊虫** | 12 种蛊虫，分为攻击 / 防御 / 治疗 / 特殊四种类型 |
| ⚔️ **装备** | 武器 + 防具 + 饰品三栏，打怪掉落或商铺购买 |
| 🔥 **融合** | 8 条配方，两蛊合一，最高合成五转灭世蛊 |
| ✨ **杀招** | 月光斩 · 雷火天降 · 天威浩荡 · 不灭金身 |
| 🏰 **福地** | 三层副本：外围雾狼 → 内围雾蛟 → 核心雾龙＋涅槃蛊 |
| 🏆 **成就** | 石魔杀手 · 福地之主 · 蛊虫炼师 · 福地征服者 等 |
| 💾 **存档** | 自动存档＋5 个手动档位，关闭浏览器不丢失（localStorage） |

## 🎨 界面

- 宣纸暖色底＋墨色文字＋朱砂点缀
- 成就徽章采用印章样式
- 移动端自适应：底部状态条 ＋ 上滑抽屉面板
- 衬线古风字体（宋体 / 楷体 / 思源宋体）

## 🛠️ 技术

| 层 | 选型 |
|------|------|
| 页面 | 纯静态 HTML |
| 样式 | CSS（古风主题，768px 响应式断点） |
| 逻辑 | 原生 JavaScript（全部内联，零依赖） |
| 存档 | 浏览器 localStorage |
| 部署 | GitHub Pages（免费 CDN） |

## 🚀 本地运行

```bash
# 方式一：直接用浏览器打开
open index.html

# 方式二：用本地服务器（可选）
npx serve .
# 然后访问 http://localhost:3000
```
